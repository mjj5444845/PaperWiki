# PaperWiki · 论文百科

论文百科是一个收录人机交互及相关领域论文介绍的个人阅读库，通过论文条目与基础概念条目整理研究方法、主要发现及相关知识。

[访问论文百科](https://mjj5444845.github.io/PaperWiki/)

## 领域范围

- 交互技术与评估
- 人机智能交互
- 人类与机器人交互
- 众包与人类计算
- 协作系统与组织
- 推荐与信息筛选
- 社交计算
- 设计伦理与社会参与
- 设计研究与方法
