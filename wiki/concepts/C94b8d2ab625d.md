大语言模型（large language model，LLM）是从大规模数据中学习语言规律，并根据上下文生成或处理文本的模型类别。在本文涉及的机器人与交互研究中，LLM 通常以 Transformer 为基础，用于解释指令、组织对话、生成计划和调用其他模块；视觉语言模型及多模态模型还可接收图像等输入。模型生成语言的能力与机器人可靠感知、执行和安全控制之间，需要额外的系统连接。[^transformer][^review]

## 从上下文到输出

Transformer 的注意力机制使用查询、键和值表示输入，通过查询与键的匹配形成权重，再对值加权求和。多头注意力让模型并行组织不同表示关系。用于自回归生成时，掩码限制模型访问未来位置，输出层给出下一个 token 的分布；连续选择 token 形成回答。这里的 token 是模型处理的文本单位，不必对应一个完整汉字或单词。[^transformer]

训练形成参数，推理时的上下文则提供当前任务信息。Brown 等的 GPT-3 研究区分零样本、单样本和少样本提示：给出任务描述或示例后，模型直接完成新输入，不进行梯度更新。这种上下文学习不同于微调；在机器人系统中，把房间布局、工具清单或用户偏好写入提示，也不意味着模型参数已经改变。[^brown]

## 语言模型怎样连接行动

文本模型不能仅凭流畅输出保证世界中的对象位置和动作可行。机器人系统需要把传感器数据、对象描述或图像送入模型，并把模型输出限制在可解析的任务、工具或行为范围。环境变化后还需重新感知，执行失败时也要反馈结果。静态提示较易实现，却可能过时；传感器转文本便于接入文本模型，却可能丢失原始信号；视觉语言模型可以直接解释场景，但不自动解决精确定位和安全控制。[^review]

ReAct 将推理轨迹与任务动作交替组织，利用外部观察更新后续步骤。其作用是把一次性生成改成与环境反馈相连的过程；它不是关于机器人身体控制的通用保证。《How Do We Research [[人类—机器人交互|Human-Robot Interaction]] in the Age of Large Language Models?》据此与传统机器人范式提出“感知—交互—对齐”，把人的参与、社会表达及长期修复纳入分析。[^react][^review]

连续代理还需要处理历史。Generative Agents 用自然语言记忆记录经历，再结合检索、反思和计划生成行为。记忆使当前输出可以依赖过去事件，但记录、检索和总结仍可能有误；有记忆也不等于形成真实的人类心理。[^agents]

## 在本站论文中的应用

在86篇 LLM 驱动 HRI 研究的[[系统综述|系统综述]]中，模型作用分布于三个阶段。感知阶段将环境信息、情绪线索和任务请求转成语义情境；交互阶段生成对话、社会动作和协作计划；对齐阶段使用偏好、历史、反馈与规则修复不合适的行为。LLM 可以承担高层规划，同时由专门感知算法、规则和传统控制器负责其他功能。[^review]

具体而言，GenComUI 用可视化让用户检查生成计划；LILAC 把实时语言纠正用于细化人的控制空间；RobotGPT 以模拟中的运行反馈修复生成代码；SONAR 则用禁止与义务规则约束社会行为。它们分别作用于计划审阅、共享控制、任务错误修复和规范约束，不能仅以“使用 LLM”概括为同一种自主系统。[^review][^lilac]

[[SiMUSation: An Interactive Visitor Experience Simulation Framework to Support Museum Exhibition Design|SiMUSation]] 将 LLM 用于展览设计中的模拟，而不是控制实体机器人。其 Qwen3.5-Plus 模型接收角色属性、当前区域图像与文字、展品资料和参观记忆；Visitor Agent 依次进行导航决定与体验反馈，Staff Agent 回答访客提出的问题，Analyst Agent 整理完整参观后的意见。结构化输出把生成内容转成地图轨迹、状态和分析面板，设计者再据此修改布局与叙事。[^simus]

该系统的角色属性并非全部交由 LLM 自由生成：设计者指定动机与[[文化分群|文化分群]]锚点，其他属性按调查分布采样，并允许人工编辑。模拟中的“困惑”“疲劳”或“叙事理解”是供设计讨论的模型输出，不是来自真实访客的测量。参与者认可其可解释性，与它能否准确预测现实行为，是两个独立问题。[^simus]

## 局限与评价

评价 LLM 交互系统需要区分语言或代码质量、任务完成、响应延迟，以及人的理解、信任和负担。某项任务成功率较高不能证明模型理解所有情境，用户觉得回答自然也不能替代安全测试。机器人中的语言输出还可能与身体动作、目光或实际能力不一致。[^review]

LLM 生成可能包含幻觉、刻板印象、迎合或过度自信。持续记忆与多模态感知又涉及隐私，主动帮助涉及用户控制，多用户场景涉及回应和注意分配公平。SiMUSation 中过于正面的总结，便是模型输出可读、可解释却仍可能削弱批判反馈的具体例子。[^review][^simus]
