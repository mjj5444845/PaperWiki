**图形感知**（英语：graphical perception）是人从图形的视觉编码中提取信息的过程。Cleveland与McGill于1984年将数量读取分解为位置、长度、角度等基本感知任务，以实验比较其准确程度；这一框架研究的是图形理解中的数量提取部分。图形能够被看见，不等于数量能够被准确读出，同一组数字的编码与显示条件也会影响判断误差。Heer与Bostock于2010年通过[[众包|众包]]实验检验部分经典比较，并研究网格和显示大小等设计条件。[^history][^s1]

## 从图表比较到基本感知任务

Cleveland与McGill于1984年提出，把图形中的数量读取分解为位置、长度、角度、面积等基本感知任务，再用实验检验其准确程度。论文承接了此前比较条形图、圆图等形式的研究，却希望从“哪张图更好”进一步得到能用于重新设计图表的原理。其排序只针对数量提取这一重要部分，作者明确不把它视为完整的图形理解理论。[^history]

1984年的框架列出十种基本任务。这里的“任务”指读者依据哪一种视觉属性判断数量，而不是十种互不重叠的图表类型。[^history]

| 基本任务 | 读者据以判断数量的视觉属性 |
|---|---|
| 共同尺度上的位置 | 标记相对于同一尺度的位置，例如沿同一纵轴比较两个点 |
| 不对齐尺度上的位置 | 标记分别位于未对齐的尺度上，需要跨尺度比较位置 |
| 长度 | 线段或条形沿某方向延伸的距离 |
| 方向 | 线条或图形所指的方向 |
| 角度 | 两条边或线之间的夹角 |
| 面积 | 平面图形占据的大小 |
| 体积 | 三维图形的空间大小 |
| 曲率 | 曲线弯曲的程度 |
| 明暗 | 图形的深浅变化 |
| 色彩饱和度 | 颜色鲜明程度的变化 |

这些任务既不完全独立，也不穷尽全部视觉编码：方向与角度有关，圆面积的比较也可能借助直径或周长完成。作者未把色相与纹理纳入这份数量任务清单，因为它们不能无歧义地按从小到大排列，但仍可编码类别。因此，不能仅凭图形的名称断定读者只执行一种任务，也不能把这份清单当成所有[[信息可视化|信息可视化]]用途的分类表。[^history]

这条路线把图形构造与可检验的判断连接起来：优先使用较准确的基本任务，并据此改造常见图形。2010年的研究沿用部分刺激与误差定义，通过在线实验检查经典位置—长度模式，又加入同格式的角度、面积比较及网格等显示设置；后来的任务化综述则整理不同设计条件下的感知证据，而非把一次排序视为所有图表用途的最终结论。[^history][^spatial][^e]

## 编码怎样影响判断

一个百分比可以表现为同轴线段的长度，也可以表现为圆中的角度或矩形面积。读者需要从视觉差异反推出数量关系；编码形式改变后，这个判断的难度也可能改变。Heer与Bostock研究的实验1使用比较两项数量的任务，让参与者估计较小者占较大者的百分比，以便在同一种任务下比较编码。[^r1]

这种任务测得的是比例判断，而不是图表的一切用途。图表也可以支持查找、趋势概括或理解结构；一种编码在精确比例判断中误差较大，并不直接证明它在所有使用情境中都没有价值。2023年的可视化评价综述据任务和设计等维度整理实验，强调把设计结论与评价条件一起理解。[^e]

## 实验怎样量化感知误差

2010年论文在实验1A与1B中，以绝对百分比误差为基础，计算$\log_2(|\text{judged percentage}-\text{true percentage}|+1/8)$。其中判断值是参与者填写的比例，真值来自图形数据；加入$1/8$使完全正确时的对数仍有定义。实验2记录参与者调出的透明度alpha，实验3使用0—100数据量程，先识别两个标记值中较小者，再估计较大值减较小值的差，以所判断的差值与真实差值之间的绝对差计误差。实验1的指标是对数比例误差，实验2是调节后的alpha值，实验3是差值估计的绝对误差；三者具有不同单位。[^r1]

以自拟数值演示实验1的指标：若图中两个标记的真实比例为50%，参与者判断为40%，先取绝对差10个百分点，再以数值10计算\(\log_2(10+1/8)\approx3.34\)。若恰好判断为50%，结果为\(\log_2(1/8)=-3\)，仍是有限数；该误差值越小，表示判断越接近真值。这是公式的教学例算，不是论文中新报告的参与者结果。[^r1]

实验1A报告了按每幅图计算的对数绝对误差的中间两四分位均值（midmean），降低极端回答的影响；另外按判断类型计算误差均值，并以自助法构造95%置信区间。这是比例判断实验的汇总程序，实验2与3分别分析透明度调节和差值判断。线上实验还需处理未理解题意或不认真作答等质量问题。[^r1]

| 实验因素 | 所改变的视觉条件 | 与结论相关的限制 |
|---|---|---|
| 位置、长度、角度、面积等编码 | 同样数量如何映射为图形 | 结果针对论文的比例任务 |
| 矩形宽高比 | 面积相同但形状不同 | 宽高比及是否排列为树图是不同条件 |
| 网格线透明度 | 辅助线可见但不抢眼的程度 | 背景强度与线条密度是分别操纵并检验的条件 |
| 图高和网格间距 | 显示大小与参考结构 | 不等于字越小或图越大越好 |

## 空间编码的比较结果

实验1A将位置、长度、角度与圆面积放入同一种比例判断任务。位置编码显著优于长度；面积表现差于角度，角度与面积又都显著差于位置。这支持了部分心理物理预期，但“角度应差于长度”的预期没有得到本实验支持。旧研究的位置—角度与位置—长度实验任务格式不同，而2010年的同格式比较仍未支持这一项排序，因而结果不是所有编码都能依理论排成严格的单一阶梯。[^spatial]

## 从空间编码到显示细节

矩形实验说明，“面积编码”内部也有差异。作者操纵矩形宽高比，并比较独立矩形与树图等条件；其结果不能简化为所有矩形一律比所有正方形准确。论文比较宽高比为2/3、1和3/2的组合，结果是两个都为正方形的面积比较误差最大，且独立矩形和树图之间未发现显著差异。作者推测读者借边长估面积可能产生偏差，仍需后续建立模型。[^r2]

网格实验要求参与者分别完成两种调节：任务L把网格调得尽可能浅，同时仍能清楚辨认并用于读图；任务D把网格调至其认为再明显就会过度干扰、浮到图像前方的程度。前者要求保留可用的可见性，并非测量刚刚能够察觉刺激的感觉阈限；二者回答不同的显示设计问题。实验发现图形密度有显著影响（$p=0.015$），背景强度没有显著影响（$p=0.779$）；不同背景强度的观测差别在该实验中未达到统计显著。作者给出约0.2的不透明度作为其条件下的折中建议，而不是适用于所有显示器和配色的普遍常数。[^r3]

图高实验发现40像素图形比80像素条件的判断表现差，而继续加高并非总带来显著收益。网格间距10与20数据单位、50与100数据单位的事后比较均未发现显著差异，而40像素高、网格间距10数据单位这一密集条件下误差陡增。作者据此建议网格至少相隔8像素；8像素是从这些条件提出的设计建议，并非实验逐一测得的通用临界阈值。其任务采用0—100量程，80像素以上准确度趋于平台的结论也要保留这一条件。设计问题因而不只是有没有网格，而是参考信息能否在有限空间内提供帮助而不过度干扰。[^r3]

## 线上测量与质量控制

众包使研究能够较快招募参与者，但参与者的显示设备和环境未由实验室统一。论文将线上结果与已有实验结果比较，以考察能否复现主要模式；复现相似排序并不表示所有设备、群体和任务都已被覆盖。[^r4]

质量控制本身也会改变样本。作者观察误答、排除极端估计，并讨论报酬、完成时间与结果的关系。例如，更高报酬没有在所比较条件中稳定改善感知准确性；这不能推广为研究劳动无须合理报酬，而是说明支付额度与认真程度、参与者构成之间不是一个简单的单变量关系。[^r4]

## 在本站论文中的应用

《[[Crowdsourcing Graphical Perception: Using Mechanical Turk to Assess Visualization Design]]》将图形感知既作为待研究的视觉问题，也作为检验线上实验方法的案例。编码比较和网格透明度实验用于与既有研究对照；矩形面积及图高、网格间距实验则扩展设计条件。其价值在于提供任务、误差定义和显示条件明确的证据，而非仅按研究者喜好推荐图表。[^s2]
