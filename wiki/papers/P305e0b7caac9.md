《A Taxonomy to Structure and Analyze Human–Robot Interaction》是Linda Onnasch与Eileen Roesler提出人与机器人交互（[[人类—机器人交互|human–robot interaction]]，HRI）描述性分类体系的综述论文，2020年6月29日在线发表，收入《International Journal of Social Robotics》2021年第13卷第4期，页833—849。论文针对机器人、使用情境和交互安排差异造成的研究比较困难，把场景描述组织为交互情境、机器人和团队三个簇，并提供可并列填写的图形画布。作者通过《星球大战》机器人和既有动作识别研究演示分类如何揭示差异；这些应用属于描述性分析，没有新增参与者实验或验证分类预测效果。[^p1][^p6][^p15]

## 背景与研究位置

同样被称为“[[拟人化|拟人化]]”的研究，可能改变机器人的外观、运动方式，也可能只改变名字、故事或介绍文字。它们测量的结果也不相同：有人研究参与者是否犹豫毁坏机器人，有人研究道德困境中的牺牲选择，还有人研究协作之后是否愿意为维修捐款。本文认为，若不说明机器人实际执行什么任务、人处于什么角色，以及接触发生在什么环境，就容易把不同操作产生的结果误认为同一现象的相互矛盾证据。[^p2]

论文表1集中展示了这一问题。Darling等人的故事框定研究考察击打机器人前的犹豫；Nijssen等人的在线研究比较人、类人机器人与机器式机器人被牺牲的选择。Onnasch与Roesler自己的既有研究则让参与者与具身NAO合作，再以为虚构维修捐款衡量救助意愿：当介绍没有额外强调机器人对完成任务的功能价值时，拟人框定反而降低捐款；补充功能价值后，该差异消失。作者据此强调，毁坏、牺牲和维持协作对象的功能不是同一种交互任务。表1没有提供可用于合并计算的样本量、效应量或置信区间。[^p2][^p3]

这种情境敏感的观点有更早的实验背景。Goetz、Kiesler与Powers在2003年区分“越积极、越讨喜越好”的假说与“线索应匹配任务”的假说，分别研究机器人外观与职业适配，以及严肃或活泼举止与任务的关系。他们报告，偏好和服从取决于任务匹配，不能概括成类人或活泼设计在所有工作中更有效。这为理解本文为何将任务和形态分开记录提供了背景，但不是对本文分类体系的直接验证。[^goetz]

分类体系在德国联邦职业安全与健康研究所（BAuA）资助的“人—机器人团队”（Mensch-Roboter-Teams，F2369）项目中，与HFC Human-Factors-Consult GmbH共同开发。论文致谢说明，本文以前述机构的baua:Fokus平台于2016年发表的短文为基础；参考文献将该文列为Onnasch、Maier与Jürgensohn的《Mensch-Roboter-Interaktion—Eine Taxonomie für alle Anwendungsfälle》。[^history]

## 既有框架及整合理由

作者回顾的框架各有重点。Granda等人的五阶段包括有限自主、遥操作、监督自主、自适应自主和虚拟共生；本文指出，监督自主与自适应自主之间缺少清楚的切分点，阶段可能重叠，而人的角色又常被统一称为操作者。Scholtz细分监督者、操作者、维修者、队友和旁观者，能够描述人的地位，却不足以交代交互本身。Schmidtler等人依据工作时间、空间、目标和身体接触区分共存、合作与协作，但主要面向工业场景，也没有充分展开自主性。[^p4]

Yanco与Drury将人的角色、交流和机器人特征放入综合分类，但有些变量缺少可直接套用的层级。Beer等人的模型深入讨论自主性，本文认为其服务机器人范围仍需扩展；Dautenhahn的相关框架关注自闭症治疗和社会技能，Kahn等人的心理基准偏重概念目标。Steinfeld等人的共同指标覆盖人、机器人和系统，但侧重任务导向的移动机器人。表2列出这些来源及其焦点，作用是说明设计基础，而不是性能排名或[[系统综述|系统综述]]的筛选流程。[^p4][^p5]

论文因此提出三项要求：同时描述人、机器人、交互和情境；能够用于多类HRI场景；提供预定义类别，使不同研究可以按共同维度比较。它整合已有分类资源，没有提出新的机器人控制算法。[^p5]

## 分类如何运作

分类的输入是一个具体交互场景及其描述。分析先确定宏观情境，再描述机器人承担的工作与设计，最后记录团队关系；输出是一张场景画布。不同画布的对应格可以并排比较，设计者也可反向检查：若改变任务、人的角色或交流方式，哪些条件需要重新安排。[^p6]

| 分类簇 | 主变量 | 要回答的问题 |
|---|---|---|
| 交互情境 | 应用领域、接触形式 | 为什么使用机器人，以什么方式、在什么设置中接触它？ |
| 机器人 | 任务、形态、自主程度 | 机器人做什么，呈现哪些线索，各工作阶段由谁承担？ |
| 团队 | 人的角色、团队构成、交流通道、邻近性 | 人如何参与，多少人和机器人参与，信息与时空关系如何组织？ |

三个簇合计九个主变量；接触形式、形态、自主程度及邻近性内部还包含子维度。它们共同描述场景，不能压缩为一个代表交互质量的总分。[^p6]

### 交互情境：用途、呈现与设置

应用领域有工业、服务、军事与警务、太空探索、治疗、教育、娱乐和无特定领域八类。分类依据是当前实际用途，而不是产品最初的市场定位。例如，Cozmo原是娱乐玩具，但在与自闭症儿童互动的相关研究中，本文把它归入治疗性伴侣。纯感知研究若没有可识别的应用背景，可以选“无”。[^p6][^p7]

接触形式需要作两组判断。第一组区分具身接触（embodied）与图示呈现（depicted）：前者强调身体在场和直接触觉互动的可能，后者包括屏幕代理、图片以及真实机器人的视频。因此，视频里出现实体机器人不等于参与者与它具身接触。第二组区分现场与实验室；在线研究也归入实验室设置。[^p7]

设置的差异可能改变研究结果。作者引用同一机器人在实验室中使儿童积极参与、进入学校现场后却逐渐令人厌倦的研究，并转述新奇性消退、重复接触及现场环境中的故障等解释。其中机器人可能卡住而无法脱困，说明设置变化既影响人的反应，也影响系统能否正常完成工作。[^p7]

### 机器人任务：八类工作目标

任务分类用抽象目标对齐不同领域的工作，而不是直接用产品名称代替任务。八类任务的含义如下。[^p78]

| 任务 | 分类依据及原文例子 |
|---|---|
| 信息交换 | 获取、分析环境信息并传给人，例如太空探索或搜救中的信息传递。 |
| 精密作业 | 完成人难以稳定实施的细致动作，例如手术机器人抑制医生震颤。 |
| 身体减负 | 降低人的搬举、承重或固定负荷，例如动力外骨骼。 |
| 运输 | 把物品从一个位置送到另一个位置，例如仓库包裹或医院布草运输。 |
| 操纵 | 物理改变环境或处理物体，例如焊接和抓放。 |
| 认知刺激 | 通过言语或非言语交流促使人参与认知活动，例如教学互动。 |
| 情绪刺激 | 引发情绪表达和反应，例如海豹机器人Paro。 |
| 身体刺激 | 以身体运动训练为目的，例如hirob模拟马背运动以训练躯干控制和稳定性。 |

运输强调位置变化，操纵强调对环境或物体的物理处理；两者在具体系统中可能同时存在。身体减负与身体刺激则按目标区分：外骨骼承接负荷，康复设备安排训练运动，不能因为都作用于身体就合并成一类。[^p78]

### [[机器人形态|机器人形态]]：分开记录四类线索

机器人形态在这里不限于外壳，而包括外观、交流、运动和情境信息四个维度。每个维度分别判断为拟人、拟动物或技术式。因此，一个外观看起来像箱子的机器人，也可能因宠物名字或动物声音形成拟动物感；一个技术式机械臂，也可能通过介绍故事获得拟人背景。分类试图保留这种组合，避免用“像人”概括整个系统。[^p8]

作者没有把卡通化单列为第四类，因为漫画化可以修饰已有类别：Hexbug Nano是漫画化的昆虫，仍属于拟动物；NAO是漫画化的人，仍属于拟人。作者还强调，各种线索的表现具有程度差异，应逐维度辨认。[^p8]

形态的重要性在于它可能组织使用者对自然语言交流、知识、能力和自主性的期待。但作者没有完成新的形态量表验证，也没有推荐现有Godspeed相关问卷直接承担四维编码，尤其指出拟动物性没有得到充分测量。论文未提出经过可靠性验证的新形态测量工具。[^p8]

### 自主程度：四阶段分别判断

[[机器人自主程度|机器人自主性]]用来描述交互中对人类介入的需要。本文区分信息获取、信息分析、行动选择和行动实施四个阶段；画布中的decision-making与正文的行动选择相对应。把它们分开，可以表示机器人独立收集信息，却仍由人决定下一步动作等不同分工。[^p89]

该结构借鉴Parasuraman、Sheridan与Wickens的自动化模型。原研究把功能类型与自动化等级交叉考虑，并要求结合人的工作表现、系统可靠性和行动后果评价设计；自动化可能改变人的工作和协调要求，而非仅减少操作。本文取其分阶段结构，用于场景描述。[^parasuraman]

本文将其所述的十点尺度简化为低、中、高三级，理由是便于概览和直观使用，但没有给出三档的数值切分阈值。图2画出系统A与系统B在四阶段的自主程度组合，是概念示意，没有实验测量值。其图注标注参考文献[18]，而邻近正文将基础模型归于[25]，存在内部引文编号不一致。[^p89]

### 团队：角色、规模、通道与时空关系

人的角色不是机器人能力的另一种说法，而是人如何参与当前任务。本文从既有角色框架中删除维修者：维修被视为人对机器人进行的功能性操作；同时把队友进一步拆为协作伙伴和合作伙伴，以区分同级关系中的行动依赖。[^p9]

| 人的角色 | 目标、控制与依赖关系 |
|---|---|
| 监督者（supervisor） | 监控机器人并指示如何执行任务。 |
| 操作者（operator） | 直接控制机器人，处于较高控制层级；例如拆弹机器人或手术机器人的操作者。 |
| 协作伙伴（collaborator） | 与机器人共享总目标和子目标，行动依赖机器人，无管理责任，处于同级；例如机器人持握、旋转工件，供人持续加工。 |
| 合作伙伴（cooperator） | 共享总目标，但通过严格分工分别完成工作，彼此没有直接行动依赖；例如装配线上的独立分工作业。 |
| 旁观者（bystander） | 没有共享任务目标；在典型共享空间情境中仍需协调避撞，例如医院访客遇到布草运输机器人。 |

团队构成以人数\(N_H\)和机器人数\(N_R\)表示，记录\(N_H=N_R\)、\(N_H>N_R\)或\(N_H<N_R\)。作者建议再写出具体数量：一人面对两台机器人和一人控制一百台机器人，虽然都满足同一不等式，工作要求仍可能大不相同。[^p10]

交流通道以机器人为参照。输入表示人向机器人提供信息，包括电子遥控、机械引导、声学口令和光学手势；输出表示机器人向人传递信息，包括触觉振动、声学声音和视觉动作。外观拟人性与通道种类需要分别记录：声学输出既可以是人类语言，也可以是动物式叫声或技术蜂鸣。[^p10]

空间邻近性根据工作区及身体接触关系编码，时间邻近性则另行记录。[^p10]

| 空间类别 | 原文所指关系 |
|---|---|
| following | 长时间保持稳定身体接触，可通过机器人接口或机器人持有的物体实现；不是日常意义的尾随行走。 |
| touching | 共享工作区，在近距离直接接触。 |
| approaching | 在同一空间紧密工作，但不发生身体接触。 |
| passing | 工作区部分或全部重叠，同时防止接触。 |
| avoiding | 避免直接接触，人保持在机器人作用范围之外。 |
| none | 不在同一工作环境。 |

时间同步表示同时工作，异步表示在不同时间工作，如轮班安排。远程火星车说明，人的角色可以是监督者，而空间邻近性同时为none；空间分离并不取消任务关系。[^p10]

### 画布填写规则

图1把情境放在深灰区域、机器人变量放在中灰区域、团队变量放在浅灰区域，左侧留给机器人、任务和具体交互的描述。每个变量至少选择一个类别；部分变量允许多选，作者将接触形式、形态、自主程度和人的角色中的相应类别视为互斥。分类同时区分子维度和任务阶段，同一机器人可随情境改变其分类。[^p6][^p10]

作者将这种紧凑表示与Business Model Canvas联系起来，并提供交互式PDF下载入口。文章中的画布本身已展示分类结构，但它不会自动填补既有研究未报告的条件，也不会从类别直接计算哪一种设计更好。[^p10]

## 应用一：R2-D2与C-3PO

作者选取两个虚构角色，是为了用较易理解的例子展示完整编码。这里编码的是故事世界内的人与机器人关系，所以两者都属于服务领域、具身接触、现场设置，四阶段自主程度均高；它不是把观看电影的观众归为与机器人现场交互。[^p11]

| 分类项目 | R2-D2 | C-3PO |
|---|---|---|
| 任务 | 导航相关精密作业及维修中的操纵 | 翻译、外交中的信息交换 |
| 外观与运动 | 技术式 | 拟人 |
| 交流形态 | 对人的音调表达带有拟动物联想 | 拟人 |
| 情境信息 | 作为有经历和性格的队友，属拟人 | 拟人 |
| 人的角色 | 监督者 | 协作伙伴 |
| 典型人数关系 | 一名飞行员与一台机器人，\(N_H=N_R\) | 两人与一台，或一人与两台机器人，\(N_H>N_R\)或\(N_H<N_R\) |
| 输入／输出 | 声学／声学与视觉 | 声学、光学／声学与视觉 |
| 空间关系 | 维修时passing；导航时none | approaching，即近距离共同工作但不接触 |
| 时间关系 | 可同步或异步 | 翻译通常同步；送信可异步 |

R2-D2的精密输入服务于导航，维修则直接处理环境；使用者给出指示并监督它，行动实施由机器人承担。C-3PO的翻译需要人提供谈话内容，同时人依赖其输出，但它可以决定如何表达、改述或拒绝翻译。作者据此把客户与翻译者的关系归为同级协作，不能仅因人提出请求就判定为直接操作者。[^p11][^p12]

在解释喜爱度时，作者提出两条可能路径。R2-D2的宠物式交流、小于成人的身体以及需要监督的关系，可能引发照护倾向；C-3PO的成人式形态和共同完成任务的角色，则可能带来严肃、专业的期待及感知上的共享责任。它们是基于既有偏好报告和分类比较提出的事后假说，本文没有重新测量喜爱度，也没有隔离形态、角色或期待的因果贡献。[^p13]

图3只突出C-3PO的同步选项，第4.1节正文还允许送信任务为异步。这一差异体现图中的代表场景与正文讨论的任务范围不同，不能把图示当成该角色全部活动的唯一编码。[^p11][^p12]

## 应用二：拟人动作为何得到相反结果

Kuz等人的研究报告，拟人轨迹和速度曲线有助于提前判断机器人动作；Riek等人的研究则报告，机器式轨迹比平滑、类人的运动更有利于动作识别。本文没有重新分析两项研究的原始数据，而是检查它们究竟是否在研究相同的交互。[^p2][^p13]

Kuz场景使用虚拟单臂装配机器人，在黑白网格中放置物体，参与者观察并预测终点。图4补充其模拟为六轴龙门机器人，并以放置圆柱为例。Riek场景使用BERTI类人躯干的视频，任务是执行三种交互手势；图4说明它有双臂，每臂七自由度、每手九自由度，颈部和腰部还具有相应运动自由度。两者都改变技术式与拟人式运动，但运动在任务中的功能不同。[^p13][^p14]

| 比较条件 | Kuz等人场景 | Riek等人场景 |
|---|---|---|
| 应用领域 | 工业 | 本文正式重分类为无明确领域 |
| 机器人任务 | 正文归为操纵 | 信息交换：用手势表达意义 |
| 外观 | 技术式机械臂 | 拟人躯干 |
| 运动的作用 | 完成物体放置的手段 | 运动本身就是交流任务 |
| 呈现与设置 | 图示呈现、实验室 | 视频图示呈现、实验室 |
| 自主程度 | 从参与者视角为高 | 从参与者视角为高 |
| 人的角色与数量 | 旁观者，一人一机器人 | 旁观者，一人一机器人 |
| 输出与邻近性 | 视觉输出、时间同步、空间none | 视觉输出、时间同步、空间none |

正式应用将两组参与者都归为旁观者，因为他们没有直接控制或监督任务。这里旁观者的使用范围扩展到被动观察模拟或视频，与角色定义中典型的共享空间情形存在张力；空间none仍另行保留。自主程度描述的是参与者感知中的独立执行，不涉及对实验系统后台是否有人为控制的验证。[^p13][^p15]

输入条件则没有同样清楚的证据。Kuz研究的输入可能为电子通道，但描述没有明确报告；Riek场景也可能使参与者预期手势的光学互惠，原研究没有讨论。图4在Riek的电子和光学输入旁加问号，没有将其确定为双通道输入系统。[^p13][^p14][^p15]

作者认为，应用领域、任务和形态上的差别，尤其“运动作为操纵手段”与“运动就是交流”的区别，可能解释相反结果。因此，两项结果不足以得出拟人运动普遍更好或普遍更差的结论；这一比较也没有提供新的统计检验来证明差异的具体原因。[^p15]

图表还保留了两项不可忽略的内部差异。表1曾用supervisor/passive描述相关参与者，而第4.2节正式分类改用bystander。图4又把Kuz任务以粗斜体标为information exchange，但第4.2节及其结论明确按manipulation解释。正文与图表对这一变量的标记不同；表中的比较采用正文所述的操纵类别。[^p3][^p13][^p14][^p15]

## 用途、限制与后续研究

作者提出，画布可帮助判断哪些研究可以作整体解释、哪些维度需要在综述中分开，也可为元分析编码和未来实验的系统变量变化提供结构。但本文实际展示的是虚构案例与既有研究的分类，没有开展元分析，也未报告分类者一致性、类别完备性或预测表现的检验。跨越治疗机器人和工业机械臂等场景推广结果，仍需另行论证。[^p6][^p15]

其直接限制包括既有论文信息不全、类别不全互斥、形态测量工具不足，以及自主性三级未给数值切点。画布可以暴露这些缺口，不能自行消除缺口。论文没有报告数据库、检索式和筛选数量，因此其框架回顾也不宜改称具有完整检索流程的系统综述。[^p45][^p6][^p89]

后续研究对其使用可具体见于2026年的《Advancing a taxonomy of proxemics for socially aware robot navigation》。该研究在第4.1节及图5a分析本文三簇结构，并与其他HRI分类一起抽取、对齐变量，转用于社会导航中的空间关系分析。它同时指出，一般HRI分类不足以覆盖该领域所需的人体特征、环境限制和动态空间因素。这是针对特定任务的继承与扩展，不是证明原分类已覆盖所有HRI变量。[^later]
