《ProjecTA：用于导览的具备原位投影功能的半人形机器人教学助理》是Hanqing Zhou、Yichuan Zhang、Zihan Zhang、Wei Zhang、Chao Wang和Pengcheng An发表于CHI 2026的系统与评估论文。它面向机器人带领新手在创客空间不同设备间移动的导览，将[[原位投影]]、语音和身体手势协调起来，使说明出现在被介绍的实物上或附近。24人的被试内比较发现，投影条件的[[外在认知负荷]]较低，感知[[可用性|可用性]]、视觉显示有用性及多模态互补性评分较高；导览后测验未发现显著差异。论文同时提出了投影与指向协同、空间放置及多模态编排的设计方向。[^identity][^results]

## 背景与研究问题

论文所称移动式学习（nomadic learning），是学习者和机器人在空间中移动，并在分布于不同位置的外部对象旁共同学习。胸前屏幕适合以机器人为主要视觉焦点的近距离交流，但设备导览还要求学习者不断查看真实机器。图文与实物分开时，学习者需要在两者之间寻找对应关系；投影的设计目标是减少这种搜索和整合，而不是降低设备原理本身的复杂性。[^background]

已有系统提供了不同的技术起点。Funk、Mayer和Schmidt的2015年装配辅助系统采用固定的上置深度相机与投影仪，根据工作步骤提供现场指引。ProjecTA则把投影带到不同设备旁，以导览体验为评价对象；两者的任务和参与者不同，固定装配中的效果不能直接作为移动导览的结果。[^projection]

机器人手势也需要与情境配合。Sauppé与Mutlu在2014年比较了六种指示形式及六类情境，说明机器人指示不限于伸指指向，具体形式的适用性受距离和任务条件影响。ProjecTA选择以投影箭头和高亮补充机械臂方向提示，让同一指涉同时具有身体线索和场景中的视觉标记。[^deictics]

研究的问题是：相较使用机身屏幕的对应系统，原位投影机器人怎样影响创客空间导览中的学习体验？主要考察的是负荷、显示帮助和通道协调，并非验证机器人可以替代教师。[^background]

## 形成性研究

### 线上构思与四项设计机会

六名机器人或HCI专家分成两组，各参加约2.5小时线上工作坊。研究者通过Figma提供相关案例、机器人演示和讨论模板。专家用20分钟描述现有情境，再用30分钟构造目标情境，随后讨论投影优势及其可迁移性。13个目标情境经亲和图分析形成四项设计机会。[^formative]

| 设计机会 | 具体作用 |
|---|---|
| DO1：定位对象与位置 | 用投射在线索目标上的箭头或突出区域补足粗略指向，例如标出工件应钻孔的位置。 |
| DO2：内容邻近物理参照物 | 把教材放在所述对象旁，例如在护理模型旁显示步骤，减少反复回看。 |
| DO3：补充或概括语音 | 在讲解现场提供摘要、背景材料或过程图，辅助理解口述内容。 |
| DO4：显示隐藏信息 | 在附近表面呈现遮挡部件或视线外物品的信息，使其进入[[共同注意|共同注意]]范围。 |

研究者据此选择创客空间新手入门导览：设备分散，各自需要专门说明，可同时探索上述机会；重复向新手介绍设备也符合教学助手分担标准化任务的定位。形成性研究在这里提供设计输入。[^formative]

### 身体风暴与六项设计需求

现场活动由一名创客空间教育者兼管理者和两名资深创客参加，三人均有超过六年经验。他们用35分钟依次围绕六类设备，轮流扮演机器人，演示讲解、手势、图像及摆放位置，并在每段演示后讨论调整。录像用于整理动作，口头说明用于提取学习点。[^requirements]

| 需求 | 对呈现方式的要求 |
|---|---|
| DR1：原理、操作与安全 | 说明设备怎样工作、怎样使用以及需要避免什么危险。 |
| DR2：内容联系与转场 | 比较相关设备，并明确何时结束当前说明、前往下一处。 |
| DR3：指示注意对象 | 用手势引导学习者关注设备、区域、方向和投影内容。 |
| DR4：强化具体或抽象概念 | 用图像性动作表现尺寸和操作，用隐喻性动作表达禁止、警告等意义。 |
| DR5：简明图文 | 采用清晰简图、短标签和关键数字，突出距离、温度、尺寸或紧急停止位置。 |
| DR6：时间协调 | 讲到某一步时显示对应图片，指向某区域时出现相应视觉线索。 |

活动使用四类手势提示卡：[[指示手势]]指向实体或位置；图像性手势描绘具体物体或动作，例如双手间距表示宽度；隐喻性手势以空间动作表达抽象概念；节拍手势是与语音节奏对应的小幅动作。最终手势库明确包含前三类，未报告纳入节拍手势。专家共提供18个指示、15个图像性、12个隐喻性示例。[^requirements]

空间安排参考F-formation：设备及投影位于中央共享焦点O-space，机器人与学习者围绕其形成R-space，P-space是外围旁观者空间，后者未纳入研究场景。该准则让教学焦点围绕设备组织，而不必始终集中在胸屏正前方。[^formation]

## 系统与呈现编排

### 硬件和导航

机器人包括移动底盘、手势执行模块和头部投影模块。手势模块有两条各六自由度机械臂及Linkerbot二十自由度灵巧手，使用Jetson Orin Nano控制。Aurzen ZIP投影仪为720p、100 ANSI流明，具备USB-C连接和自动对焦，装在Seeed Xiao-ESP32C3控制的二自由度云台上。头部安装既不占用手臂的动作空间，也提供周向投影范围，减少躯干对背向投影的遮挡。[^hardware]

Wheeltec S300底盘配双M10P激光雷达，沿同时定位与地图构建（SLAM）地图和预设设备位置导航。投影及云台经Wi-Fi上的MQTT连接控制电脑，手势模块和底盘通过CAN总线及ROS话题控制。面部LED呼吸灯表示说话状态。导览偶尔需要人工进行小幅导航调整，因此运行包含人工支持。[^hardware]

### 从教学目标到执行文件

呈现编排工作流以设备选择和顺序为教学目标，并接收三类先验知识：预先收集的设备资料、围绕原理操作安全整理的关键学习点，以及来自专家演示的叙述技巧。后者包括日常类比、设备间比较和转场提示，每台设备的叙述约四至五分钟。[^workflow]

第一阶段由GPT-4o-2024-08-06生成讲稿，显式标记每个学习点的位置，以便人员核验并为后续资源选择提供索引。第二阶段使用MiniMax合成语音，按语义边界切分，每段至多包含一个关键学习点，记录时长和对应学习点。视觉来自预建图像库，每张记录投影位置、文字描述和关联学习点；复杂步骤可对应多张图。[^workflow]

手势库把45段专家动作中的高度相似示例合并，形成42个机器人控制序列，经遥操作录制为ROS bag文件。每个单元记录机器人位置和朝向、描述、设备与学习点上下文、配套叙述及持续时间。一个学习点可以对应多个动作；图像和动作并不是导览现场自由生成的。[^workflow]

第三阶段先由语言模型逐语音段判断是否需要视觉或动作补充，查询资源元数据后选择图像、手势或二者组合，再按规则对齐时间。单图通常覆盖整个语段；多图各自对齐它解释的讲述时刻；手势随语音播放，若动作超过语段长度，则延长段间停顿，防止重叠。教育者和技术人员可以预览并微调。[^workflow]

Dify与上述模型构成离线流水线，所有推理在导览前完成，以避免现场推理延迟并允许人工检查。输出是叙述、视觉和手势三份带执行时间的JSON文件，由后端转成同步行为。本研究没有独立比较不同模型或编排策略的性能。[^workflow]

### 一个完整导览情境

图4用示例人物Jeff与Jerry串联设计。机器人先投射箭头定位FDM打印机，再以简图标记顶部自动换料系统和下方底座；讲解结束后用方向动画和语音提示转场。到焊台时，步骤图放在工具附近，随讲解从等待冷却切换到松开螺母，随后显示安全警告。[^scenario]

树脂打印机的固化过程不易现场直接观察，因此机器人以过程图补充语音，接着指向机盖解释安全机制，再引导查看废树脂处理说明。到激光切割机时，机器人放大展示内部难见的聚焦镜，并以遮眼动作配合避免直视激光的警告。这个情境说明定位、近物体说明、过程图解和隐藏结构可视化怎样落实到设备介绍；两位人物不是额外实验样本。[^scenario]

## 比较研究

### 参与者与条件控制

研究招募24名新手，13男、11女，年龄20—31岁，平均24.25岁、标准差2.61。参与者组成12对，其中六对相识、六对陌生；14人具有工程或科学背景。19人从未参加创客空间动手活动，22人从未参加设备导览。附录B图12显示，六类设备熟悉度均无人选择五级量表的第四或第五级，24人对尼龙打印机均选择最低熟悉度。[^study]

投影和胸屏条件使用同一套硬件与编排实例，匹配讲解、资源、路线和时序。Baseline有两项屏幕适配：指向投影的动作改成提示看屏幕；落在实物上的箭头、光环和高亮，改为显示在同一设备照片上。因此，两条件保留相同讲解意图，但手势并非逐动作完全相同。[^baseline]

每对完成两轮、每轮约15分钟的导览，12名参与者先体验投影，另12名先体验屏幕。A套设备是FDM、树脂和尼龙打印机，B套是焊台、3D扫描仪和激光切割机。两套内容不重叠，套组顺序在显示顺序内部再平衡，以减少重复学习及顺序影响。现场两名研究者负责引导和记录，第三人在邻室操作后端。[^study]

### 评分、测验与访谈

每轮先问卷、后测验。表1的25项评分分工如下。[^measurement]

| 项目 | 测量对象 |
|---|---|
| RS1—4 | 内在负荷：材料复杂性及已有知识相关的努力。 |
| RS5—8 | 外在负荷：呈现造成的可避免努力。 |
| RS9—11 | UES-SF中的专注注意。 |
| RS12—14 | 感知可用性；反向计分后越高越好。 |
| RS15—17 | 审美吸引力。 |
| RS18—20 | 回报感。 |
| RS21 | 视觉显示对理解内容的帮助。 |
| RS22 | 视觉显示对关注实际设备或区域的帮助。 |
| RS23—25 | 视觉、手势和语音的感知互补性。 |

前八项采用[[认知负荷|认知负荷]]量表，RS9—20来自用户参与量表简版，最后五项为自编项目。认知负荷为十一点评分，其余为五点。每轮测验有30项单选或排序内容，覆盖三台设备的原理、操作和安全；正确选项或排序中正确位置各一分，再线性归一化到0—100。问卷造成短暂间隔，但测验仍是近期评价。[^measurement]

互补性量表在投影和屏幕条件下的Cronbach α分别为.75和.72；RS21—22在两条件下均低于.70，故分别分析。研究检验个体内差值的正态性，对内在负荷、外在负荷、专注注意、可用性和测验使用配对t检验，其余使用Wilcoxon符号秩检验。[^results]

双人[[半结构访谈|半结构访谈]]围绕可见性、正负体验、具体协调成败、偏好及潜在应用。两名研究者协作归纳编码，四名研究者定期讨论发展编码方案，将引语聚成主题层级，并用录像和照片补充空间情境。这是[[主题分析]]在体验解释模块中的作用。[^qualmethod]

### 近物体显示与共同观看

23/24人报告设备旁的线索减少了眼部或头部来回移动，11/24人认为较少担忧查看实物时错过讲解。这些来自访谈，研究未报告眼动测量。胸屏要求两人靠近狭窄观看区域，可能换位、拥挤或相互遮挡；投影把共享图文区域移到设备附近，使共同焦点接近教学对象。[^qualitative]

图11展示关键数字放大和难以看见的设备部件等情境；紧急停止按钮定位见图7④，背面送料卷轴与内部喷嘴则由该节正文叙述。13/24人报告投影触发了主动靠近、查看和核验。隐藏结构的图解使部件信息可见，并不意味着光线穿透设备投到内部。主动探索是本研究中的体验发现，尚未直接验证长期概念理解的变化。[^qualitative][^social]

### 通道之间的互补与竞争

投影能把机械臂方向收束到具体对象：转场时先出现箭头，再接指向动作；设备拥挤时用目标表面的光环缩小搜索范围。图示也承担空间描述，使“这个设备”或“这个部件”可以和可见标记共同完成指涉。[^multimodal]

15/24人回忆图像性或隐喻性动作强化讲解的例子，包括用双手示意扫描范围并配数字、模拟戴手套并配防护提醒，以及用遮眼、推手或挥动强化安全警告。与此同时，P11和P12认为手势与投影有时争夺注意，P19和P23认为指向偏斜，转而主要看投影。部分参与者希望语音提前预告图像或动作。[^multimodal]

投影还会受到机械运动抖动、环境强光、斜面透视畸变和物体遮挡影响。对于复杂内部部件，部分参与者希望使用照片等更高保真材料；简单图文的清晰性不能替代所有结构细节。[^qualitative]

## 设计方向与证据边界

作者提出四组方向。第一组让手势与投影共同指向目标，并在被指向的投影图内部加局部箭头、边框或高亮；无接触标记也可用于危险、易碎或难触及部位。第二组精细安排投影位置，把O-space和R-space扩展为三维体积，结合视野、观看锥及遮挡决定使用胸屏还是投影，并引入几何与辐射补偿。[^implications]

第三组把移动投影扩展为协作界面，呈现行动意图、路径或计划，并通过点击、描画和区域选择接收输入。第四组改进编排，使用行动前语音提示及停顿，把关键词、动画关键帧和手势微步骤分别计时，并明确哪个通道此刻主导。例如详细图示主导时减少无关身体动作，动作主导时简化或调暗图像。这些方案属于未来建议，没有在本文获得新的对照验证。[^implications]

研究使用预编排讲解，不支持导览中问答，未测量长期保持、真实设备实操或安全行为，也未验证屏幕与投影同时使用。样本来自单个大学创客空间，且工程科学背景较多。活动按12对开展，统计以24名个体配对，正文未报告额外处理双人组相关性的模型或多重比较校正；也没有分别移除手势、语音或改变编排策略的消融，因而不能分离各组件的因果贡献。[^limits][^study][^results]
