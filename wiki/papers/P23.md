《技术探针：启发为家庭及与家庭共同开展的设计》（Technology Probes: Inspiring Design for and with Families）是2003年发表的设计方法论文，提出把简单、可实际使用的技术放入日常生活，结合使用记录与共同反思来探索未来设计。研究在 interLiving 项目中部署数字便签 messageProbe 和静态影像 videoProbe，同时追求了解家庭生活、检验工程实现和启发新设计三个目标。美国、瑞典和法国的家庭分别把设备用于日程协调、涂画游戏及远程影像交流，也暴露出故障、摆放和既有关系对使用的影响。论文的成果是方法及设计线索，而非证明某个家庭通信产品提高效率的受控实验。[^p1][^p5][^p6][^p7]

## 背景：为什么先放入一种可用的技术

interLiving 研究跨家庭、跨代际的联系。儿童、父母和祖父母在能力、兴趣和作息上不同，家中设备又要与家具、美观和私人生活共处；在办公室以效率为中心建立的设计假设，不能直接回答家庭想怎样保持联系。作者因此希望让家庭成员成为参与设计的伙伴，而不是等研究者决定产品形态后，才评价按钮或界面细节。[^p1][^p2]

论文区分“访谈—研究者设计—用户测试”的通常流程与早期共同探索：如果技术概念已经固定，用户意见容易局限于既有方案；但在从未体验过的通信形式面前，单问想要什么也未必能产生具体建议。最初项目计划放入示范性的“种子技术”，后来转向探针，让使用者在真实生活中接受、拒绝和重新解释技术，再以这些事件展开讨论。[^p2]

这种方法延续[[文化探针|文化探针]]用相机、日记等材料激发反思的思路，但并不只收回一次任务结果。技术探针持续作为生活中的物件运作，还记录自身怎样被使用。作者明确接受设备会改变原有行为：研究的问题既包括家庭原本怎样交流，也包括新可能出现后，人们如何适应或改造它。作者将这种开放关系称为共同适应（co-adaptive）：人适应新技术，也为自己的目的创造性地改变其用途。[^p2]

Dunne与Raby的Placebo Project也把引发思考的技术放入家庭一段时间；两者的具体区别是，技术探针让设备记录自身如何被使用，再把这些记录带回家庭与研究者的共同反思。[^p2]

## 三种目标与研究过程

一个探针需要同时满足三方面要求。社会科学方面，要在使用现场了解人及其关系；工程方面，要使设备确实能在家庭长期运行，不能像演示时那样隐藏网络与安装问题；设计方面，要留下用途的开放性，促使研究者和家庭想象尚未预定的技术。这三者有张力：功能越完整越容易像固定产品，技术过于简陋又可能让人只看到故障。[^p2]

论文把部署前后的家庭访谈、行动日志与低技术原型工作坊结合起来。日志记录日期、时间和操作，可重建何时有人写入或查看；访谈补充行为为什么发生；工作坊再以真实经历中的成功和失误为情境，请家庭用纸、黏土等做出另一种方案。在这项研究中，日志与参与者解释共同帮助团队理解行为的不同含义。原文强调部署期间及之后的分析反思，并说明可以有多种实施方式；访谈、日志和工作坊是团队在本项目中采用的组合。[^p2][^p3][^p7]

### 与原型的五项区别

作者用五个方面说明技术探针的研究角色，而不是按外观把设备分为“粗糙”或“精致”。其中“不在部署中根据反馈修改”针对探针阶段，并不否定之后另做原型和迭代设计。[^p3]

| 方面 | 技术探针的要求 | 与文中所说产品原型的区别 |
|---|---|---|
| 功能 | 通常一个主功能及两三个容易使用的辅助功能 | 原型可组合多层功能，尝试满足多种既定需求 |
| 灵活性 | 功能少，但容许用户重新解释用途 | 原型通常已有较明确的目标和预期用法 |
| [[可用性|可用性]] | 不以持续优化操作为首要目的，可故意缺少某功能 | 原型会根据反馈改变界面、改善操作 |
| 日志 | 收集真实使用，作为双方反思材料 | 原型也能记录数据，但不必把记录本身作为主要目标 |
| 设计阶段 | 早期挑战预设，寻找值得设计的方向 | 原型较晚出现，逐步改进某个已选择的方案 |

这一区别解释了为什么一个能运行的装置仍可以只是研究工具。判断探针是否成功，要看它是否让人遇到新经验、揭示问题并产生设计讨论，而不能只问用户是否喜欢这一台设备。与此同时，工程可靠性仍有底线：设备完全不工作，便无法产生足够的生活经验供反思。[^p2][^p3]

研究还对探针的选择提出情境要求：不必是研究领域内全新的技术，但对家庭应足够新颖，以激发他们重新思考通信方式。messageProbe 与 videoProbe 对习惯把技术等同于桌面电脑的家庭提供了不同体验。尽管安装宽带、硬件和软件故障都带来额外回访，作者报告两类探针均在家庭中部署一个月或更长时间，使反思能够建立在持续使用而非一次演示上。[^p3]

## messageProbe：共享数字便签

### 操作与设计取舍

messageProbe 把分散住户连接到同一个可缩放便签空间。家庭成员用笔在可书写液晶屏或连接显示器的绘图板上书写、画图，没有鼠标键盘操作；它只连接一小组预先选定的亲属，不必输入地址或维护好友名单。各地可以同时写同一张便签，也可隔一段时间查看新内容，因此同时支持同步互动和异步留言。[^p3]

点击虚拟便签本创建新纸条，点击已有纸条把它放大，点外部则缩回全局。任何人都能移动或修改他人创建的纸条。新便签立即传到所有设备，在相同位置显示；默认按创建时间排列成网格，旧便签向上移动并缩小。使用者可拖出网格另作安排，拖回时恢复时间顺序，系统会重新填补空位。共享空间因而既提供初始秩序，又不规定每家必须怎样分类。[^p4]

便签保留纸张式书写与涂画，却无法像纸条那样贴到任意物件；它换来的是远距离共享和近乎无限的便签供应。设计删除了标题栏、日期、复杂图标和对话框，也没有删除纸条的功能。简化界面旨在让它不像通常的电脑，但后来的使用显示，缺少删除也会让人担心犯错。这种结果正是需要回到生活中观察的设计取舍。[^p4][^p5]

messageProbe结合三条设计来源：工作场所共享白板及将其带入家庭的ScanBoard，支持多人书写；远程感知研究，关注分隔家庭如何保持联系；可缩放用户界面，提供在便签细节和整个共享空间之间切换的方式。[^p4]

系统用 Java 实现，使用 Jazz 支持缩放、Java Shared Data Toolkit 2.0 及 XIO 支持相关功能，可运行于 Windows 与 Mac OS X。纸笔式界面并没有消除硬件差异：美国部署只有一块直接书写的液晶屏，其余住户使用分开的绘图板与显示器；瑞典两户则都配备液晶屏与 Apple Cube。[^p3][^p4][^p5]

### 美国：协调需求与参与不均

2002年初，美国试验持续六周，连接同一扩展家庭的三户：一户父母和两名学龄儿童，以及双方祖父母。三户相距不超过15公里，两户祖父母由研究者提供电脑和高速网络。设备尽量放在经常经过的位置，但仍须服从家庭意见；父系祖父母的设备在地下室，比厨房和主起居区偏僻。[^p4]

六周共创建超过120条消息，每户都有人至少每天查看。两名祖父写得最多，其次是父亲；儿童只写少量，母亲和祖母各一两条。双方祖父母虽能看见所有内容，却几乎不直接交流，访谈表明这与原来的亲属关系一致，不能仅据共享功能存在，就推断各方会自然形成新的通信网络。[^p4][^p5]

消息包括状态、近况、情绪和接送儿童等协调，其中不少状态更新其实是在报告技术故障。母亲更愿意打电话，儿童常忙于其他活动；没有删除功能让一位祖父先在纸上打草稿。网络、调制解调器、IP及笔输入干扰又影响了可靠性。不少美国家庭成员希望增加新消息的通知，例如声音提示；他们认为设备有趣，但重要且需迅速回应的沟通仍以电话更合适；这些观察把“需要更方便交流”细化为谁、在何种情境、需要怎样的回应。[^p5]

### 瑞典：既有亲密关系中的游戏

瑞典的部署于2002年夏持续数月，连接两姐妹各自的住户：一人与男友同住，另一人与丈夫及两个年幼孩子同住。一个设备放在卧室电脑旁，因光和噪声夜间关闭；另一个置于楼下闲置餐桌，可从多个房间看见。全家留下超过200条便签，但使用主要延续两姐妹原有的密集沟通，而非每个成员同样投入。[^p5]

姐妹和孩子在便签上连点画、涂鸦，并从两端反复添加内容，写满后继续下一张；孩子甚至争抢笔。瑞典家庭讨论过提示对方正在写字的声音或视觉信号，同时担心它在忙于其他事情时造成打扰。这与美国对新消息到达通知的明确需求形成不同侧重。他们还遇到设备偶尔不工作和缩放较慢的问题，但家庭成员仍表示喜欢该探针，认为它给彼此的关系增添了新维度；这是使用者自述，而非关系质量量表的结果。相比美国案例，研究者看到了更多嬉戏，但两组部署的时长、设备、家庭组成和原有关系不同，消息总量不能作为国别效果比较。[^p5]

## videoProbe：用静态影像保持远程感知

videoProbe 在画面大致稳定三秒时自动拍下图像，上传后可供相连住户查看；家庭成员用遥控器浏览，图像随时间淡去并最终消失，以鼓励新的记录。它分享的是偶发的静态照片，不是一直开启的视频通话。使用者也能用可转向、可取出的摄像头拍摄附近物件。[^p5][^p6]

作者选择静态图有三项理由：家庭中实时视频的网络实现更困难；静态记录同时容许异步和接近同步的交流；让人主动与设备互动，能留下便于记录和讨论的行动。硬件包括 Apple Cube、Wacom PL-500 显示器、Philips ToUCam Pro 摄像头、扬声器、USB遥控及无线联网，软件用 C++ 和 videoSpace 工具包实现。Apple Cube 没有风扇，但硬盘仍被部分家庭抱怨有噪声，说明选机时对安静的考虑仍未消除家庭中的噪声问题。[^p6]

显示部分封入简洁的白色外壳，可放在家具上、平躺或挂墙，摄像头通过顶端凹槽固定方向。遥控器专门重新标记，因为普通录像机的快进、播放等图标，不能清楚说明“把照片加入或移出相册”。这些实现细节关系到家庭能否把设备当作日常物件，而不仅是研究员暂时放置的电脑。[^p6]

### 法国部署及早期观察

2002年夏，四台 videoProbe 安装到两组法国家庭关系中。一组是住在巴黎的两姐妹，一户把走廊设计成“媒体墙”，另一户允许墙上安装，但随后搬家，留下的数据有限；另一组是相隔约20公里的两兄弟家庭，设备放在主起居区桌面或边柜，须与花瓶、植物和灯一起安置。四台设备对应四个住户、两组亲属网络。[^p6]

初步观察包括孩子和年轻人做鬼脸、拍奇特近照，以及拍下手写便条来传递文字。作者明确预计用途会随更长期的整合继续变化，未在此报告长期使用率或与 messageProbe 的优劣排名。搬家、空间布置和网络安装都构成研究条件，而不是可以从数据中删除的偶发噪声。[^p3][^p6]

## 从观察到新的设计

美国部署后的工作坊把便签中的协调失误变成具体情境，请家庭分组用纸、线和黏土构思。父母设计可连接手机的冰箱共享日历，希望协调全家日程；祖父母想知道谁在家，提出门口钥匙钩和有人要联系时会夹一下的戒指；儿童较少使用固定便签，转而构想可随身携带的语音钥匙链及显示放学后安排的手表。不同方案说明，同样说“保持联系”，各代人需要的对象、地点和方式并不相同。[^p7]

另一条方向来自瑞典便签游戏和法国视频中的鬼脸：远程家庭联系不只有安排任务，也包括一起玩。作者于是提出家庭协调与嬉戏两类后续原型，并关注选择与谁交流以及增强已有家用物件。这些构想是由探针经验产生的后续设计方向，文中尚未报告长期部署或产品效果验证。[^p7]

## 方法的边界与后续解释

本研究的证据来自少数设计伙伴家庭，没有随机分组、统一的效率指标或跨国代表性样本。设备故障限制了重要通信，参与也明显不均；但这些失败并未自动使探针失去价值，因为它们揭示了可靠回应、通知打扰及家庭关系等需求。作者对成功的判断是产生理解、讨论情境和新设计想象，而非给出产品性能的因果证明。[^p5][^p7]

Boehner 等2007年的探针文献分析，把技术探针列为探针方法的重要变体，同时强调打开新设计空间与迭代完善单一产品的区别。他们更广泛地批评把反思性探针机械当作客观需求采集工具的倾向；这属于方法论讨论，不是对这些家庭观察作统计反驳。[^review]

Alan Dix 为《Human-Computer Interaction》编写的2015年在线材料，则用早期可实际运行的高保真原型来解释技术探针，并以 Hermes 门旁显示器等说明其在家庭之外的延伸。教材的“原型”用法比原论文更宽，二者共同点是让人通过真实体验看见用途，不能因此抹去原论文对探针研究目的的区分。[^book]
