《SiMUSation：支持博物馆展览设计的交互式观众体验模拟框架》是Huanchen Wang、Qiuming Chen、Zhonghao Ji、Ruqi Sun、Zhichao Lu和Yuxin Ma署名的2026年人机交互研究论文，提出供策展人与展览设计者在早期检查空间和叙事方案的观众模拟系统。系统将观众画像、二维环境和参观记忆输入大语言模型，逐步生成可观察行为及内部响应，再由设计者依据个人与群体反馈修改方案。12人研究报告SUS平均分79.38，四位专家对修订设计的评分总体高于初稿；研究没有检验模拟对真实观众行为、情绪或理解的预测准确率。论文列于UIST ’26，预印本提交于2026年8月17日。[^identity][^results][^limits]

## 背景与研究位置

作者关注展览开放前缺少观众反馈的问题。专业直觉可能使设计者忽略不同观众的知识、动机和身体条件，而实施后观察、访谈及问卷又难以及时支持早期修改。路线和停留记录能够显示观看分布，却不能单独解释叙事理解、困惑或情感联系。SiMUSation因此把模拟定位为设计参考，将支持对象从游客端导览转向策展和设计工作流。[^background]

其理论背景之一是[[学习情境模型]]。Falk与Storksdieck于2005年对217名成年科学中心访客的研究发现，多种条件共同参与学习，没有单一因素可以解释所有访客的结果。这支持从组合条件理解体验，但不能直接证明语言模型能准确模拟这些条件的作用。[^context]

智能体架构提供另一条背景。2023年的Generative Agents以自然语言记忆保存经历，通过检索、反思和规划组织行动。SiMUSation引用该工作，并将状态、环境与累计经历用于连续观众模拟。SiMUSation正文未报告是否复用了Generative Agents的完整反思与检索算法。[^agents][^simulation][^implementation]

## 形成性研究与设计目标

研究团队先招募7名20—50岁的参与者，平均30.86岁，3女4男，包括从业者、研究者和学生，领域经验为2—24年。每人参加90分钟Zoom会话，报酬100元人民币。任务设在卢浮宫德农馆一层红区，以文艺复兴绘画为主题，提供平面图和50幅相关馆藏画作。参与者通过作品分组、顺序和空间放置构思叙事，标出预期路线和不确定区域，再接受[[半结构访谈|半结构访谈]]。[^formative]

访谈形成三类困难。第一，多种观众条件交织，设计者难以预想不同人如何理解和行动，容易依赖个人经验。第二，评估多在布展或开放后进行，行为记录又难以揭示内部体验，单一标准不足以评价不同观众。第三，文档和草图使修改繁琐、零碎，缺少能够支持修订的量化与定性反馈。参与者认为二维画布虽非理想，但足以支持早期工作，并希望工具提供参考，由设计者保留创作控制。[^goals]

作者据此提出三个目标：支持有依据且多样的画像构建；提供动态模拟及个人、群体层面的量化和定性反馈；将反馈接入交互编排环境，支持自主修改。正文进一步将方法分为四个组件：画像智能体构建、展览空间与叙事编排、体验模拟与表示、多粒度反馈。图1把它们概括为“画像与展览—体验模拟—评估分析”三个区域，这是工作流层面的分组。[^goals]

## 画像与展览输入

### 三个画像维度与双锚点

画像首先描述参观前能够指定的观众侧条件。个人维度包括[[身份相关动机]]、先验知识、既往参观经验和兴趣。动机采用探索者、促进者、专业人士或爱好者、体验寻求者、恢复者五类。社会文化维度包含[[文化分群]]，以及独自、与朋友或与家人同行的关系。物理维度包含预期参观时长和体力。展览环境及参观中的互动另在后续模拟中处理，不能把画像中的物理维度当作原学习情境模型全部物理环境条件。[^personas]

设计者指定身份相关动机、文化分群及画像数量，其余属性从文化和博物馆观众调查的经验分布抽样，之后可以逐人编辑。双锚点用于降低配置负担，不表示仅有四类画像，也不表示全部属性由语言模型生成。MHM官方将Culture Segments定义为基于文化参与动机的细分模型，因此该锚点不只是人口统计标签。[^anchors][^mhm]

作者把调查抽样解释为减少幻觉或依据薄弱属性组合的办法，同时保留组内差异；本文没有报告相对于纯语言模型生成的消融结果。具体调查来源、分布和抽样映射指向补充材料。[^anchors]

### 三层环境编排

系统以带拓扑关系的二维网格表达展览。作者依据形成性研究选择二维，希望降低空间推理负担，同时保留路径、连通性和接触叙事内容的条件；没有报告二维相对三维的性能实验。[^environment]

空间层配置墙、入口、出口、通道及具有功能或叙事名称的分区，规定可达边界。展品层在分区中布置作品，附上图像、内容、背景、艺术家和媒介等多模态信息。设施与员工层加入互动装置、休息区和工作人员，表达可能影响参观的运营条件。完成后，布局转换为JSON，供智能体感知和决策。移动休息点、加入过渡区或调整展品位置，因而会改变后续模拟的环境输入。[^environment]

## 体验模拟机制

### 三路输入与状态更新

每一步结合画像状态、局部环境和记忆。画像状态包括动机、知识、兴趣、文化分群、同行关系，也包含体力和预期时长等动态条件；先前模拟的经验可用于表示回访者。记忆累计已看展品、走过路线及本次体验，使后续行动能够参考此前经历。[^simulation]

环境可见范围限制在当前分区，通过布局图和可访问展品、设施、员工的结构化描述输入；访客不是一开始就知道全展。选定具体展品后，智能体才进一步接收作品图像与元数据。感知阶段读取这些材料；决策阶段选择移动、观看、与装置互动、询问员工或休息；反馈阶段根据动作后果更新状态、记忆及后续信息访问，再进入下一步。例如休息可能减轻疲劳，工作人员的解释可能改变之后的注意和路线。[^simulation]

### 双层体验表示

输出以可观察行为和内部响应两层对齐呈现。行为层包含移动导航、观看与信息获取、记笔记或素描等参与行为，以及与同伴交谈等社会行为。内部响应分为认知理解、情感和意义价值三个维度：分别涉及内容与先验知识的联系，兴趣、困惑或无聊等感受，以及身份认同、反思或恢复等体验。系统由此允许设计者同时检查“做了什么”和模拟给出的体验解释。[^simulation]

两层并置并不使内部响应成为真实心理测量。同样的停留可以伴随投入，也可能伴随困惑；系统展示的是模型生成的对应关系，其现实准确性需要另行验证。[^simulation][^limits]

### 原型与三个智能体

原型为Web应用，使用Vite和Vue.js构建前端，FastAPI管理后端请求，LangChain编排循环，核心模型为Qwen3.5-Plus。作者选择该模型的理由是视觉语言理解和空间推理能力。[^implementation]

Visitor Agent先进行导航决策，依据画像、位置和此前经历选择接近的实体；到达后生成体验反馈，包括具体行为、响应和内在归因，并在结束时总结。Staff Agent在访客提问时依据策展叙事生成导览对话。Analyst Agent将完整轨迹和反馈整合为结构化参观后总结，突出体验模式与潜在设计问题。三个智能体角色与两层体验表示属于不同分类；所有角色采用可机器解析的输出格式。[^implementation]

## 分析界面与指标

五个面板分别负责展览编排、画像设置、地图模拟、群体分析和个体体验。编排面板支持上传平面图、设置分区、检索展品及配置设施员工；画像面板支持指定锚点和数量生成、完全随机生成、编辑及批量删除。地图可以在编辑与模拟模式间切换，显示轨迹、交互、步骤、时间和体力。个体面板可暂停或拖动时间线，检查逐步体验、各分区时间、展品停留及最终总结。[^feedback]

系统从个体轨迹提取展品、分区、停站、时间和路线，计算行为指标并形成定性总结，再按两个画像锚点聚合为群体印象、满意度和建议。设计者可以从总体分布定位被忽略区域，再到个体记录检查生成过程。[^feedback]

表3规定八项指标，均是对模拟轨迹的计算。以下令N为所统计的访客总数，T为相关累计参与时长，A为展览面积，t̄为平均参观时长。[^metrics]

| 指标 | 定义与计算口径 |
|---|---|
| 访客数VC | N，即访客总数 |
| 平均观看时间AHT | T/N，单位秒；原表分母为VC，而非仅停下者人数 |
| 吸引力AP | 停下的访客数/N×100%；文字定义说接近特定展品，公式使用Stopped Visitors |
| 扫掠率SRI | A/t̄，面积以平方米计；作者称较低值表示较好参与，该行未指定时间单位 |
| 勤勉访客比例%DV | 在严格超过50%展品处停下者人数/N×100% |
| 穿行率WR | 未在任何展品停下者人数/N×100% |
| 平均停站数 | 总停站数/N |

## 设计场景

作者以Lily的情境说明完整闭环。她策划城市发展如何重塑人与自然关系的临时展览，设置导向厅、自然画廊、城市画廊和反思区，并建立关注生态与地方地理的探索者、寻求视觉享受的体验寻求者等画像。首次模拟的群体反馈显示导向不清，反思区穿行率高、持续停站少；内容兴趣较强者仍觉得各区孤立，休闲观看者则可能只看到联系松散的场景。[^scenario]

她随后检查个体记录。Alexander（ID 2）在城市画廊投入较多时间，对城市图像有情感响应，却对其与此前风景展品的关系感到困惑和疲劳；Aiden（ID 0）较遵循预期路线，仍觉得自然画廊到城市画廊的转换突兀。Lily在导向厅增加概览地图，在两画廊之间加入过渡区，并在反思区入口附近设置休息点，再运行模拟。作者展示第二轮更连贯、持续参与的反馈。这是说明性案例，没有给出可作为实验效应量的数值。[^scenario]

## 用户研究设置

正式研究招募12名19—33岁的参与者，平均23岁，男女各6人，均至少有一年展览设计经验；其中9名学生、3名从业者，经验为1—9年。会话约两小时，现场或Zoom进行，报酬100元人民币，另由四位具有设计、美术与策展背景的专家评价产物。[^study]

任务主题为“风景中的跨文化对话”。团队通过大都会艺术博物馆官方API整理600余件相关作品的图像和元数据，参与者在预设空间中选择约20件，安排布局并构建叙事。官方API文档说明服务以JSON提供开放数据及对应公共领域图像；这支持数据接口的性质，不独立核实论文筛选的具体集合。[^study][^met]

参与者提前一周熟悉主题和数据；当天依次接受15分钟背景介绍、30分钟演示与自由探索、50分钟设计任务、10分钟问卷和15分钟访谈。团队记录无模拟初稿v1与使用模拟修订的v2。四位专家成对评价两版，设计对的顺序及对内版本位置均打乱，映射仅研究团队掌握。专家采用7点评价叙事连贯性、空间组织，以及设施和员工位置适宜性。[^study]

## 结果与分析

SUS[[可用性|可用性]]平均分为79.38，标准差7.78。其余问卷以7点量表测量参与者对模拟可靠性、接受度及设计支持的感知。[^results]

| 主观评价维度 | 均值 | 标准差 |
|---|---:|---:|
| 画像区分 | 5.42 | 1.19 |
| 行为合理性 | 4.75 | 1.23 |
| 响应真实感 | 5.25 | 1.01 |
| 体验可解释性 | 5.42 | 1.11 |
| 设计洞察 | 5.58 | 0.95 |
| 决策支持 | 5.83 | 0.80 |
| 设计信心 | 5.50 | 1.04 |
| 易于迭代、降低投入 | 5.67 | 0.62 |
| 工作流优化 | 5.75 | 0.83 |

行为合理性是四项模拟评价中最低的一项。参与者认为路线与停留适合检查早期流线及注意分布，但U4认为互动行为需要更多真实观众依据。U11最常检查内部响应，用来比较模拟观众的想法与设计意图。作者据此认为，可检查的轨迹和逐步理由有助于参与者理解并信任模拟；这仍是感知可信度的结果。[^results]

设计支持方面，U3发现即使按现实地理位置编排文化分区，模拟观众仍会忽略侧区；U4发现突出重点展品不足以让观众把握整体结构。总体指标提示问题位置，个体行为和响应则帮助理解可能原因。参与者认为编辑与反馈整合减少了人工制图负担，但研究没有以独立计时实验量化客观节时幅度。[^design]

四名专家对修订稿的三个维度总体给出更高评分。修订稿减初稿的叙事连贯性差值均值为0.67、标准差0.98，空间组织为0.65、标准差0.97；正文未给出设施适宜性的精确差值。专家评分一致性ICC(2,1)在v1为0.83，在v2为0.77。图5为专家平均评分箱线图，图6、7为12人问卷等级比例图，均不是预测准确率图。[^design]

研究比较同一参与者先完成初稿、再借助模拟修订的两个版本，未报告匹配迭代时间的独立无模拟对照组、组件消融、真实观众校准或上述改善的显著性检验。因此，这些结果支持感知可用性以及修订产物总体评分改善，不能单独建立模拟的因果收益、真实观众预测准确率或客观节时幅度。[^study][^design]

## 失败反馈与局限

U7和U4指出，即使故意布置令人困惑的展览，群体总结仍可能过于积极、批判不足；U2质疑真实观众动机是否如此明确。作者也强调，内部理由是模型生成的解释，不是人类认知真值。解释连贯与主观可信，因而不能代替现实准确性的验证。[^limits]

作者列出四类系统局限：二维表示简化真实视线和照明；经验数据画像仍可能产生刻板印象、迎合和过度积极判断；系统主要模拟个体与基本同行关系，未捕捉人群形成等动态互动；细微修改也需要重跑模拟。三维环境、微调或更广身份设置、更健全的感知模型、动态群体互动和局部增量更新属于未来方向，未在本文验证。[^limits]

资料范围也影响复现。正文将调查分布、完整提示词、体验表示细节及部分实现说明指向补充材料，而所提供15页版本的附录A—C只有形成性任务、参与者表与指标表。该版本未报告推理采样配置、成本、延迟或固定模拟画像数。样本以学生为主，任务限定于受控艺术展览，也限制了对长期策展实践和其他博物馆类型的推广。[^anchors][^implementation][^study]

## 设计讨论

作者提出让AI承担体验反馈者的角色：设计者编排空间与叙事，智能体从不同画像出发生成连续经历，设计者再据此反思和修改。学习情境模型组织输入条件，身份动机和文化分群连接画像配置与群体筛选，状态和记忆维持参观过程的连续性。作者认为，这种反馈支持应保留人的创作自主，并明确传达模拟风险和不确定性。这是基于本研究提出的设计方向，尚非跨领域验证的通则。[^limits]
