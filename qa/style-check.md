# 维基体风格自检

依据wiki-style-writer的12项清单，2026-11-01。当前是个人论文阅读项目的有来源条目，不宣称达到维基百科优良条目资格。

| 清单项 | 状态 | 复核与边界 |
|---|---|---|
| 首句识别主题与类别 | 通过 | 论文导言有题名、发表年与研究对象；概念导言定义并附英文 |
| 导言概括正文 | 通过 | 论文导言概括问题和核心研究方式，不添加无来源的历史地位 |
| 章节与资料匹配 | 通过 | 理论、架构、质性材料使用“研究材料与结果”；没有伪造算法基线或实验准确率 |
| 段落与因果 | 通过 | 区分描述、相关、模拟和条件外推；P13保留自述与无对照组边界 |
| 评价归属 | 通过 | “作者指出”等用于原文限制，没有革命性等无来源评价 |
| 日期、数字、术语 | 通过 | 统一PDF物理页码；模型拟合与测试准确率、人数与次数、实例与站点数分开；Amazon Mechanical Turk与SHAP按用户要求保留原名 |
| 关键事实有来源 | 通过（限定所用资料） | DOI与原文页码就近脚注；概念页主要说明这些论文中的定义及用法，没有自行扩写完整发展史 |
| 引注范围与书目 | 通过 | 元数据经过Crossref核对；P10的题名差异以原PDF题名为准；概念应用另补方法所在页码 |
| 信息框一致 | 通过 | 作者、年份、场所、领域、DOI来自抽取；未报告的arXiv和代码不补造；P19代码仓库单列 |
| 无自行推导或大段复制 | 通过 | 正文使用原创中文归纳；公式保留GroupLens核心预测式及符号解释 |
| 按题材调整骨架 | 通过 | 论文与基础概念分别组织；概念没有资料支持的“发展史”未凑空标题 |
| 说明剩余缺口 | 通过 | 原论文自身的模糊处在页面或QA中保留；此检查不能代替新增材料的人工审核 |

## 本轮发现并修订

- 不再强行翻译Amazon Mechanical Turk和SHAP。
- 把P21的显著结论限定到来源识别指标；总体表现无显著差异另列。
- P04的87.2%标明非留出测试准确率，并说明baseline细节缺口。
- 正文实体仅首次链接，“参见”保留导航链接；嵌套术语按最长实体识别。
- 修复Markdown表格内wikilink的竖线被误作列分隔，补齐被挤出的脚注。
- 把导言置于目录之前；移动端侧栏折叠，信息框回到单栏文流。
- 保留公式分隔符，并对导言和正文分别执行KaTeX渲染。

## 当前范围

85个概念页是围绕本站论文的简要基础知识入口，不是对各领域文献的穷尽综述。今后扩充发展、变体或争议时，必须继续补充实际阅读的可靠来源。
