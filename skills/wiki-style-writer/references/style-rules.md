# 通用写作规则

以下 G1—G12 是可复用规则，规范性要求与描述性统计应区分。

- G1 定义先行：首句交代主题名称、类别和最关键的区分特征；姓名、外文名、年代只在有用时置于括号，避免括号压过主句。
- G2 导言是全文缩影：概括主要方面，不堆满时间、奖项或职衔；短条目可用一段，长条目依主题分段。按已经核实的正文概括，不能仅靠“是”句或关键词判定概括充分。
- G3 一段围绕一个中心：先提出该段事实或背景，再给必要细节；不以机械连接词代替事实关系。
- G4 中立描述：优先写可核实的行动、规模、结果。“著名”“卓越”“最伟大”等评价须有明确归属与合理篇幅；不能简单删掉有来源且重要的评价。
- G5 归属准确：用“研究者甲认为”“据乙的调查”说明谁持何种观点，保留原来源的确定程度；“有人认为”通常不够明确。
- G6 因果有据：“导致”“促成”“为此”须有资料支持；只有时间先后时写“此后”。
- G7 主要方面充分、枝节克制：用可靠来源分配篇幅，不能给孤立观点同等权重；无来源的空白不以常识填补。
- G8 日期明确：尽量写绝对日期，避免“目前”“近年来”；采用一致的年月日格式，史历转换须有依据。同一事件的初现、命名、升级、正式成立或商业发行可能是不同日期，先查清阶段，不轻率写成“来源互相矛盾”。
- G9 数字有语境：保留单位、币种、统计时点、口径和近似词；不用无依据的小数精度，不擅自换算。
- G10 术语一致：首次出现时按读者需要解释或给外文，之后保持同一译名；正文采用用户指定的简繁变体。
- G11 章节为内容服务：按事件进程或主题关系组织，避免同级标题交叉重复；导言、信息框、正文的关键数字一致。
- G12 结尾不强行升华：结束于最后一个实质章节，必要时列注释、参考资料及外部链接；不添加作文式总结或宣传口号。编辑过程、自我检查与“这不是现实事实”等说明放在交付备注，不混入百科正文。

这些规则不要求“是”句、固定段数或统一句长。样本中出现某词不意味着该词不当；判断需看来源、归属和上下文。

## 依据与适用边界

规范性要求参考中文维基百科的[优良条目标准](https://zh.wikipedia.org/wiki/Wikipedia:優良條目標準)。本轮研究以2026-11-01列表页的18个一级领域分层，seed=42抽取200篇，另留出5个主题进行写作验证；定性导言审读为每领域1篇，共18篇。统计不能验证所有作者均为人类，也不意味着样本中的每种写法都值得沿用。

领域文件中的“样本观察”是该次样本的描述，不能作为未来文章的硬性配额。尤其不能用固定导言字数、固定引文密度或固定章节数量代替证据与内容判断。
