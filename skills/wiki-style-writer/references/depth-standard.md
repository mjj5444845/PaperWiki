# 科研论文与概念条目的信息深度

简洁指没有废话，不是信息少。先精读全文及附录、查阅背景与后续资料，再组织文章；抽取 JSON 只能作为索引，不能逐字段转写成成稿。

## 工作材料与覆盖检查

为每篇论文保留逐节笔记：物理 PDF 页码/印刷页码对应、原文各节及附录、框架的每个组成部分、算法/定义/原则全表、输入与输出、实验对象及选择理由、所有主要表格、消融或对照、作者解释、失败案例与局限。没有附录应记录“本版本未附”，不能声称查阅不存在的材料。若论文引用配套附录，应取得并阅读或明确缺口。

写 10 个从基础到细节的读者问题及作者侧答案依据；问题应在正文事实确定前冻结，避免只问现有页面已经会回答的内容。读者版本只包含问题，不泄露答案。缺失章节的理由写进精读笔记/审核报告，不在百科正文凑“无此内容”段。

## 论文每个章节回答的问题

| 章节 | 深度要求 |
|---|---|
| 导言 | 3–5句概括做了什么、所解决的问题、核心思路、主要结果及有证据的研究位置。读者不看正文也能理解大意。 |
| 背景 | 论文发表时已有方法是什么、具体不足是什么，为何需要本研究；避免只有一个问句。历史背景和今天的评价分开。 |
| 核心思想 | 先给非专业读者可理解的机制解释或恰当类比，再进入术语。类比不能冒充论文证据。 |
| 方法或内容 | 完整列出作者提出的框架、原则、定义或算法；按输入—步骤/模块—输出解释，说明关键公式的每个符号、适用假设；尽可能用原文实例走完整流程。 |
| 设计选择 | 作者为什么这样做、与什么替代方案比较；消融说明什么。没有消融不能虚构，也不能把猜测写成作者动机。 |
| 实现与研究设置 | 给出理解/复现所需的数据、参与者、模型规模、条件、资源和操作，不把名称人数堆成笔记。先解释每个系统是什么、为何入选。 |
| 实验与结果 | 对象、指标、基线、样本/分母、关键数值、作者解释、失败条件。数值表与正文解释相互补充；模拟、例算、预测与真实实验明确区分。 |
| 分析与发现 | 讲清定性主题、可视化揭示的关系和意外发现，保留证据边界及替代解释。 |
| 局限 | 原作者自述与外部评价分开归属；指出适用范围，不能把“未报告”自动改写为“没有”。 |
| 影响与后续 | 使用真实查阅的可靠外部资料，交代继承、改进、反驳、实际应用或标准演变；有影响力论文不能省略此项。不能用引用量或“意义重大”代替具体关系。 |

按题材合并或调整章节；理论论文不必造实验，设计方法论文不能套训练模型模板。省略的适用性理由必须可在审核材料找到。

## 七类不合格反模式

1. 核心内容不完整：只说提出九项原则却不逐项解释，或仅命名算法而省略运作。
2. 字段转写：从研究问题、方法、贡献、数据逐项复制成句，缺少段落论证。
3. 笔记体罗列：分号串联未解释的系统名、人数和数字。
4. 数字没有解释：缺少比较对象、口径、条件或作者如何理解结果。
5. 套话链接：“理解这一研究涉及”“可通过下列概念继续阅读”等不能充当工作关系分析。
6. 背景只剩问句，未交代当时的实际状况。
7. 空泛赞誉：“革命性”“效果显著”等没有具体来源、比较和数据。

## 密度、篇幅与视觉

- 每段有至少一项具体内容：机制、条件、方法名、数量、案例、对照或可查证的历史事件。它是人工审读标准，不用关键词打分假装质量已被证明。
- 不设字数上限。论文约4000–8000字、概念约2000–4000字只作排查深度不足的参考；原材料短时宁可短，不注水、不补无根据的细节。
- 实验核心数字用表格；方法可自行画 Mermaid 或简单流程图。不能以表格取代原因、机制和比较解释。原论文图片只有许可允许时才复制；否则原创重画并注明依据。
- 原创例算可说明同一已发表公式的运作，必须标注“示意例算，非实验结果”，不能变成原创研究结论。优先使用原文的完整算例。

## 来源与引用

- 论文的方法、实验、数字以全文为准，注明实际查阅的页码/章节。抽取短引文用于内部核对，不大量复制到成稿。图、表、公式的文字提取不足时，必须查看PDF渲染图；不能把提取乱码当作原文，也不能以猜测补数字。
- 背景、影响、后续、外部批评必须检索并阅读可靠外部来源。教材、综述、研究者/机构官方资料和重要后续研究可各承担适当角色；官方自述仍是一手资料，不能伪装成独立评价。
- 引用按段落或论点合并，不必每句加脚注；同一段材料跨出处时分清支持范围。完整书目和稳定链接放在末尾。定位使用真实覆盖论点的页码与章节；引用到同一文献不代表任何页码都能支持。
- 原作者声称、其他研究的发现与作者后来的自评分别归属。找不到来源则省略影响细节并在审核材料记录缺口，不能编造引用。
- 术语沿用常用译名，首次附英文；Amazon Mechanical Turk 和 SHAP 保留原名。

## 独立验收

用户要求独立验收或用于自动发布时：一名未读原论文的独立读者只看新页面回答冻结的10题；另一名独立复核者对照全文及外部资料核验数字、结论、引文范围和关系归属。读者至少8/10且核心内容不能缺失；事实错误需全部修正再复核。保留原答案、评分依据和修订记录，不能只宣称通过。自动处理无法完成这些步骤时转待复核，不发布。

## 修订时的证据精度

人数、访谈次数、提交次数与分组数分别计数；不能把两名研究者分担的访谈次数改成受访者身份分组。引用原例时保留是谁、做了什么、何时发生的关系，不用听起来合理的情节填空。编辑自检、版本覆盖和待核资料写入审核记录；百科正文只陈述主题及有依据的适用边界。

验收保存页面快照哈希。若只调整首链或删除未使用脚注，可以保留可验证的转换记录；事实、数字、措辞归属发生变化时须重新审校。不能沿用旧稿分数冒充新稿验收。
