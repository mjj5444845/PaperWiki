# 引用与可供查证

C1 可合理质疑的陈述就近引注，尤其是精确数字、争议事实、评价、因果解释、引语、研究结果，以及在世人物的敏感信息。同一来源能支持一整段时可在段末注明，但不能让读者猜测支持范围。

C2 使用实际查阅且能支持对应陈述的可靠来源。原始文献适合支持其自身记录，学术与历史解释优先依赖适当的研究和二手来源；来源的适用性取决于具体论断。发行方材料可以支持自家产品的发行时间、平台或设定，不能单独支持“广受好评”等独立评价。

C3 草稿中无可靠来源的位置标 `[来源请求]`。来源仅支持一部分时拆句；不得制造引用，也不能把搜索摘要当成已经读过的全文。

C4 按输出环境选择格式：普通 Markdown 用描述性链接或脚注；wikitext 可用 `<ref>{{cite web|title=实际标题|url=实际网址|...}}</ref>`、`cite journal`、`cite book`。示意字段必须替换为真实信息；未知字段留空或省略。重复来源可用命名 ref；书籍论断尽可能给核实过的页码。末尾用 `<references />` 或相应参考模板收集脚注。

C5 记录作者、标题、出版者或刊物、发表日期、卷期页码、稳定标识或网址；网页按需要记录访问日期。DOI、存档地址、页码必须真实核验。统一格式，不追求某一种模板的机械覆盖。

C6 引文密度不是质量分数。一千字多少脚注不能证明覆盖充分；检查的是每条关键论断的证据、来源质量和引注范围。剧情摘要等也不可据“例外”放宽原创解释的证据要求。

C7 论文自身事实与外部评价分层取材。背景、影响与后续须另行检索可靠资料；不能把原文忠实性误解为禁止使用外部来源。脚注可按段落或论点合并。
