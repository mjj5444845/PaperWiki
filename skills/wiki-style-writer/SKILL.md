# 维基体写作

以可查证的事实组织一篇可独立阅读的中文百科条目。遵循用户指定的篇幅、读者、文字变体和输出格式。

## 使用流程

1. 确认主题范围，整理已有来源及其能支持的事实。信息不足时先完成可支持的部分。
2. 阅读 [通用规则](references/style-rules.md)。按主题查阅 [领域骨架](references/section-templates.md)，选用有资料支持的章节；骨架不是必须填满的表格。
3. 撰写科研论文或技术概念条目时，先读 [深度标准](references/depth-standard.md) 与 [论文/概念模板](references/paper-and-concept-templates.md)，完成全文精读、读者问题和外部研究；简洁不是减少信息量。
4. 写概述身份、主要特征、发展与影响的导言，再按主题或时间组织正文。导言随正文修订，不加入正文未支持的新结论。
5. 按 [引用指南](references/citation-guide.md) 为可质疑的陈述就近提供来源。没有可靠来源时写 `[来源请求]`；绝不虚构作者、书名、页码、DOI、网址或引文。
6. 用 [自检清单](references/checklist.md) 检查内容与证据。需要示范时阅读 [短例](examples/annotated.md)。

## PaperWiki 仓库维护

维护本仓库首页、论文分类、增量批次或发布流程时，阅读 [PaperWiki 维护约定](references/paperwiki-maintenance.md)。其中包含首页文案与列表设计、批次轮换、领域归档，以及用户持续授权的“每次更新后提交并 push”要求；通用写作任务不套用这些项目规则。

## 必须保持的边界

- 区分事实、某一来源的判断及尚有争议的解释。评价注明主体；不同观点按可靠来源中的分量呈现。
- 不从材料自行推导新的因果、动机、排名或历史意义。不能因为两件事先后发生，就写成因果关系。
- 句长、引文密度和章节频率是观察结果，不是配额。信息框不是每篇必需；不得用空字段或凑章节制造完整感。
- 缺乏证据的草稿须保留来源请求；不可将其称为已符合维基百科收录或优良条目资格的成稿。
- 用户只要求写作时输出文本；发布到维基百科或其他网站属于另一个操作。
- 本 skill 为风格归纳；不复制样本长段文字。引用原句时遵守许可与署名要求。
